# Klassno to Telegram Forwarder (klasnovtg)

Автоматический сбор новых сообщений из платформы **Классно** (`myclass.team` / `api.klassno.app`) и мгновенная пересылка в Telegram-беседу через Telegram-бота.

## Возможности

- **Полная автономность:** скрипт сам автоматически авторизуется по логину и паролю при старте и перелогинивается при истечении токена (никаких ручных действий).
- **Поддержка вложений:** автоматическая отправка фото и файлов, прикрепленных к сообщениям.
- **Определение авторов:** бот запрашивает и кэширует в локальной SQLite базе реальные ФИО преподавателей и студентов.
- **Без спама историей:** при первом запуске фиксируется последний `id` сообщения — пересылаются только новые сообщения, поступившие после запуска.
- **Фильтрация:** по умолчанию свои собственные сообщения не пересылаются (`FORWARD_OWN_MESSAGES=false`).
- **Гибкость:** можно отслеживать как один чат (например, группу колледжа `28755`), так и несколько через запятую или все доступные сразу (`KLASSNO_THREAD_IDS=all`).

## Быстрый старт

### 1. Настройка Telegram бота

1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Задайте имя и юзернейм для бота, скопируйте полученный **HTTP API Token**.
3. Добавьте созданного бота в вашу Telegram-беседу (группу).
4. Узнайте `chat_id` беседы:
   - Отправьте в беседу любое сообщение (например, `/test`).
   - Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
   - Найдите в ответе объект `"chat": {"id": -100XXXXXXXXXX}`. Число с минусом — это и есть `chat_id`.

### 2. Заполнение `.env`

Откройте файл `.env` в корне проекта и укажите:
```dotenv
KLASSNO_LOGIN=YOUR_LOGIN
KLASSNO_PASSWORD=YOUR_PASSWORD

# ID чата (по умолчанию 28755 - группа 9/4-РПО-23/1)
KLASSNO_THREAD_IDS=28755

# Telegram
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
TELEGRAM_CHAT_ID=-1001234567890

# Интервал опроса в секундах (по умолчанию 15)
POLL_INTERVAL_SECONDS=15
FORWARD_OWN_MESSAGES=false
```

### 3. Запуск

В терминале (из папки проекта):
```powershell
.\venv\Scripts\python.exe main.py
```
